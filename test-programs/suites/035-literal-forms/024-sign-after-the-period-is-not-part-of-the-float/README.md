Pins that a sign after the period of a float literal is not part of the literal: `1.+5` is the float literal `1.`, the operator `+` and the integer literal `5`, and literals of different kinds cannot be mixed in arithmetic. The compiler used to read it as one literal, and C read it as `1. + 5` (issue #47). Then it read `+5` as one literal and `1.+5` did not parse (issue #48).
