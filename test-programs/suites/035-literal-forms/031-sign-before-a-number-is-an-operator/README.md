Pins that a sign before a number is an operator, not part of the literal (issue #48): `a+5`, `a -1` and `a - -1` parse, and so does a negation as the left operand. The negative literals that a place types keep their values: an argument, an assignment, the least `Int8` and the least `Int64`. The compiler used to read `+5` and `-1` as literals, so `a+5` was two operands with no operator between them.
