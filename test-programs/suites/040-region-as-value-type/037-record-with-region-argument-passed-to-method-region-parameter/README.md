Covers a record over the region of a `borrow` block, passed to a method of a concrete instance whose parameter has that record type over the method's own region type parameter: accepted, and the method reads the slot. Before, the method's monomorph took the record over the type variable `R`, a C type other than the record over the borrow's region, and the C compiler stopped with `incompatible type for argument 2` (issue #142).
