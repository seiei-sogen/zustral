Covers the arm of `negation_of_operand` (lib/LiteralTyping.ml) that keeps the negation of an operand that is not a number literal, with an operand of every kind of expression, and the alternative `ArithmeticNegation` of the expression statement in `ends_in_return` (lib/ReturnCheck.ml). The negations are read before the return check, and the function does not end in `return`, so one program reaches all of them and stops with the missing return.
