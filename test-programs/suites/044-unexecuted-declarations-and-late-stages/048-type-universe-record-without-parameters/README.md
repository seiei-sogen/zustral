A record declared in the `Type` universe without type parameters, used as the type of a slot. The universe of such a type comes from its type arguments, so it has none; the use is rejected with a declaration error (lib/TypeParser.ml, effective_universe). Nothing rejects the declaration itself. Before, the compiler stopped here with an OCaml assertion failure. Found while writing the test for lib/ExtractionPass.ml, check_slots_are_free.
