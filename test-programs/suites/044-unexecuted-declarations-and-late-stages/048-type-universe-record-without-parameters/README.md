A record declared in the `Type` universe without type parameters, used as the type of a slot of a record declared before it. The universe of such a type comes from its type arguments, so it has none. The declaration of `B` is rejected when the IDs of the module's types are reserved (lib/ExtractionPass.ml, check_type_universe_has_type_parameters), before the slot of `R` is parsed, so the error is at `B` and not at its use (#144). Before, the use was rejected, and a declaration that nothing used was not; earlier still, the compiler stopped here with an OCaml assertion failure. Found while writing the test for lib/ExtractionPass.ml, check_slots_are_free.
