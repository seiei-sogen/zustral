Borrowing a constant mutably is rejected with `I can't find a variable named c`: the borrow looks the name up only among the local variables (lib/TypingPass.ml, augment_borrow). The name can be read, so the message is not true; the test pins today's behaviour. The arm of augment_borrow that would handle a constant says that borrowing one mutably is fine, so making the lookup find constants needs a decision first.
