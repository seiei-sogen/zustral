For lib/CodeGen.ml, gen_stmt: the alternatives of the arm of `MBorrow` for a borrowed variable that is not an address (`MonoUnit`, `MonoBoolean`, `MonoInteger _`, `MonoSingleFloat`, `MonoDoubleFloat`, `MonoNamedType _`, `MonoRegionTy _`, `MonoReadRef _`, `MonoWriteRef _`, `MonoFnPtr _`). Shows what each borrow reads. The borrow of a `Static` is in a function that is compiled and not called.
