A function with both a `Foreign_Import` and a `Foreign_Export` pragma is rejected with the error for that (lib/ExtractionPass.ml, reserve_definition). The program also executes the alternatives `_ :: _ :: _` of the two matches there that read the external name and the export name from a list of one pragma. Before, the check for "both" compared those two names, which a list of two pragmas never gave, and the program was rejected later with `Only import and export pragmas are allowed inside functions.`
