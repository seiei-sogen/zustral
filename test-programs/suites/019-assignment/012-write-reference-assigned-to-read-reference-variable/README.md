Covers an assignment of a write reference to a variable of the read reference with the same underlying type and region: accepted, as the same conversion in the initial value of a `let` is (013). No call reaches the function: a caller cannot hold a read reference and a write reference of one region at once. Its body is checked all the same. Before, the assignment was a type error, `Expected a value of type &[Int64, R], but got a value of type &![Int64, R].` (issue #30).
