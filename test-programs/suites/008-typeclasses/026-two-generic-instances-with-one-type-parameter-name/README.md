Test that a method of a generic instance can call the method of another instance of the same typeclass when both instances name their type parameter `A`: the `A` of `Weighable(Option[A])` is bound to the `A` of `Weighable(Box[A])`. Before, the two were one type variable, the instance was found with no type argument, and the compiler stopped with `Parameter list and argument list don't have the same length` (issue #158).
