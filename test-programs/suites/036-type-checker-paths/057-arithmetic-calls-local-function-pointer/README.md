Pins that an arithmetic expression calls a local variable that has the name of the arithmetic method, and that its literal operand, which arrives under a cast to the type of the other operand, is matched against the parameter as a literal: 1 is accepted for a Nat8 parameter although the cast is to Int64 (lib/TypeCheckExpr.ml, augment_arithmetic; lib/TypeMatch.ml, match_type_with_value). The parameters of the `Fn` type are written in reverse because the compiler reads them so (issue #127).
