Test that, when a generic function calls itself with a reference of its own region parameter `R`, the place of the call cannot make that `R` the region `Static`. This is 107 with a region parameter: the call `launder(first, false)` is a `Two[&[Int32, Static], &[Int32, R]]`, not a `Two[&[Int32, Static], &[Int32, Static]]`. Before, the call was accepted, and because regions are not in the C, the program compiled: a reference with the region `R` passed as a reference that lives for the whole program (issues #151, #156).
