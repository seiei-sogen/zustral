A union case with the name of a record declared before it (issue #86), and a function that reads a slot of the record. The type `Circle` of the parameter holds the ID of the record, and the path `c.radius` takes the record's slots by that ID (lib/TypeCheckExpr.ml, get_record_definition). When the slots were looked up by name, the lookup found the case and the path was rejected with `Cannot take a path of the type Circle because it is not a record`. The program cannot print the slot: in a body, the name `Circle` still finds the case (test 047 and issue #86).
