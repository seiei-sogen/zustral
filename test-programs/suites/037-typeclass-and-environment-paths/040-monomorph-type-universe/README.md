A generic function over `T: Type` that returns `Option[T]` compiles and runs when instantiated with a record type: the instantiated type is the named type with its universe, so `type_universe` can answer (lib/Monomorphize.ml, `mono_to_ty`). This used to stop with the internal error `You shouldn't be asking for the type_universe of a MonoTy` (issue #128). The program prints the slot of the record it gets back.
