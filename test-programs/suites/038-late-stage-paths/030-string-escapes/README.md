Covers the escape sequences for newline, carriage return, tab, single quote, double quote and backslash in a string literal, and the same characters in the generated C string; the program prints the character codes (lib/Escape.ml, escape_list and unescape_char). In a one-line string the lexer reads `\"` itself, so the triple-quoted `"""\"z"""` is what reaches the arm of escape_list for `\"`. The source used to write `\\"` for the double quote, which only worked while the lexer read `\\"` as a backslash and an escaped quote (issue #133).
