An instance that does not define a method of its typeclass fails where it is declared, also when the method is called only on a type parameter (issue #91). Before, the instance was accepted, the type checker did not see the call (it resolves the instance only for calls on concrete types), and the error came with no span when the generic function was monomorphized (lib/Monomorphize.ml, the TVarMethodCall case of monomorphize_expr).
