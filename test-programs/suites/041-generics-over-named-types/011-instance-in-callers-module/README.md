The typeclass and the constrained generic function are in a library module; the record and its instance are in the module that calls the function. The type checker accepts the call. Monomorphization then looks for the instance among those visible from the generic function's module, does not find it, and stops with `Typeclass resolution failed`, without a span (lib/Monomorphize.ml, the `TVarMethodCall` arm; issue #128). This pins today's behaviour: the program is correct and should compile.
