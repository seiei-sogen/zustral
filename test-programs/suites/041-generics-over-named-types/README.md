Generic functions and types instantiated with named types (records and unions). Monomorphization puts the named type itself into the instantiated body (lib/Monomorphize.ml, `mono_to_ty`), so the type checker's functions that run there (instance search, binding a type parameter, the universe of a type) see the same type they would see in source. The printed output shows which code ran. Before, several of these stopped with `Typeclass resolution failed. Dispatch type: MonoTy)` or with an internal error about the universe of a `MonoTy` (issue #128).
