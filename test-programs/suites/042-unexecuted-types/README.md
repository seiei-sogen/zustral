Programs that execute lines of the type modules (lib/Type.ml, lib/TypeMatch.ml, lib/LiteralTyping.ml, lib/TypeReplace.ml, lib/TypeParser.ml, lib/MonoType.ml, lib/TypeBindings.ml, lib/TypeSystem.ml, lib/TypeStripping.ml) that no other test program executed. Many of those lines are alternatives of an or-pattern over the constructors of `Type.ty` or of a typed expression, and a line counts as executed only when every alternative on it is, so most programs put one constructor into one position. Tests 001 to 009 are written by hand; 010 and after are one error each, generated from one template per group (the README of each names the line). Lines that no program can execute have their reason in the record of unexecuted lines instead.
