lib/TypeMatch.ml, try_match_type, the `RegionTy _` alternative of the mismatch arm for an expected `Unit` (lines 56-58). The type parser accepts a region as the argument of `Pointer` (`Pointer[Static]`), so a function that takes `Pointer[Unit]` can be called with a `Pointer[Static]`: matching the two pointed-to types compares `Unit` with the region `Static`, and the call is a type mismatch.
