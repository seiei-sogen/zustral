lib/TypeMatch.ml, try_match_type, the `RegionTy _` alternative of the mismatch arm for an expected `Integer` (lines 75-77). The type parser accepts a region as the argument of `Pointer` (`Pointer[Static]`), so a function that takes `Pointer[Int32]` can be called with a `Pointer[Static]`: matching the two pointed-to types compares `Int32` with the region `Static`, and the call is a type mismatch.
