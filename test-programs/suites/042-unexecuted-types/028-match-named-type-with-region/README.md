lib/TypeMatch.ml, try_match_type, the `RegionTy _` alternative of the mismatch arm for an expected `NamedType` (lines 101-102). The type parser accepts a region as the argument of `Pointer` (`Pointer[Static]`), so a function that takes `Pointer[Tag]` can be called with a `Pointer[Static]`: matching the two pointed-to types compares `Tag` with the region `Static`, and the call is a type mismatch.
