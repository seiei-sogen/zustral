lib/TypeParser.ml, decl_type_signature, the `UnionCase _` arm: a parameter's type is the name of a union case that `Zustral.Pervasive` imports. The type is not a local type, so the parser looks the name up among the declarations, finds a union case, gets no type signature, and reports an unknown type. Before issue #86, the programs in which a case had the name of a record of the module executed this arm.
