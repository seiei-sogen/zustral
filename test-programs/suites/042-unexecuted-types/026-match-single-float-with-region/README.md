The type parser accepts a region as the argument of `Pointer` (`Pointer[Static]`), so a function that takes `Pointer[Float32]` can be called with a `Pointer[Static]`: matching the two pointed-to types compares `Float32` with the region `Static`, and the call is a type mismatch.
