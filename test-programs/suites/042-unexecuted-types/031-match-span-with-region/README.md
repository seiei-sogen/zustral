lib/TypeMatch.ml, try_match_type, the `RegionTy _` alternative of the mismatch arm for an expected `Span` (lines 141-143). The type parser accepts a region as the argument of `Pointer` (`Pointer[Static]`), so a function that takes `Pointer[Span[Int32, Static]]` can be called with a `Pointer[Static]`: matching the two pointed-to types compares `Span[Int32, Static]` with the region `Static`, and the call is a type mismatch.
