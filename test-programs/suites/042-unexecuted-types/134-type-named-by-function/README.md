lib/TypeParser.ml, decl_type_signature, the `Function _` arm: a parameter's type is the name of a function that `Zustral.Pervasive` imports. The type is not a local type, so the parser looks the name up among the declarations, finds a function, gets no type signature, and reports an unknown type. Before issue #28, a program that declared a record under the name of an imported function executed this arm.
