lib/TypeReplace.ml, replace_tyvars_expr: the arms for a float constant, a conjunction, a negation and an if expression (lines 19, 72-86). Monomorphizing a generic function replaces the type variables in every expression of its body; this body has one expression of each of these kinds, and a disjunction and a comparison (the lines of their arms have the same text as the conjunction's). The output is the float and the two booleans the body prints, then the value it returns.
