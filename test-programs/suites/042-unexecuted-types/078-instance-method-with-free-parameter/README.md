lib/TypeClasses.ml, check_method_type_parameters_are_regions, with a type parameter in the `Free` universe: a typeclass method has a type parameter of its own, `U: Free`, and the program fails where the typeclass is declared (issues #128, #157). Before, the methods of an instance without type parameters were compiled as they were written (Monomorphize), so `U` was never replaced, and the compiler stopped with the internal `strip_type': Variable not replaced` (lib/TypeStripping.ml, strip_type), which this test was for. No program reaches that line now; the unit test `a type variable left for the code generator` (test/UnexecutedDeclarationsTest.ml) executes it.
