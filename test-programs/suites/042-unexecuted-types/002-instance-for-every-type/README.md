A typeclass has an instance for one type of each constructor, and a method call looks for the instance of its argument's type by matching every instance of the typeclass against it, skipping the ones that do not match. The calls dispatch on a value of each type, so each instance's argument is matched against every other constructor. The `Pointer` instance is declared first because an instance declared after a `Pointer` instance is reported as overlapping it (#122). The output is the name of the instance each call reached.
