Pins the numbers in the names the compiler generates (`_t`, `tmp`, `_tmp_ref`) for statements nested in every way: in the branches of `if` and `case`, in loops, in borrows, in a function, a generic function and an instance method. The numbers follow the order the compiler visits the statements in, which is not the order of the source: the statements of a block are numbered last to first, and the `else` branch before the `then` branch. Nothing in this directory states the expected names; the equivalence check (tools/refactoring/equivalence.py) compares the generated C with that of the base compiler. The unit test test/CompilerTest.ml states the numbers of a smaller program outright.
