An error about a borrow in the value assigned to a path: `wantsStatic(&t)` passes a reference whose region is not `Static`. The borrow of `&t` is anonymous, so the message names its region by the name the compiler gave the borrow, `_tmp_region_2` (the borrow of the target `s` is `_tmp_region_1`). Before (issue #144), the message had the number the type checker gave the region, 4, which depended on the order it numbered the regions in.
