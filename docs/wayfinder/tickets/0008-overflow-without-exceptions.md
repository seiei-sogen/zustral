## 問い

10進演算が表現可能な桁を超えたとき、何が起きるのか。

Austral には例外がなく、整数演算はトラップするか明示的にモジュラ演算を使う。
10進でも同じ二択にするのか、別の答えが要るのか。

- トラップする（プログラムを落とす）。金融バッチで許容できるか
- 結果を `Option` / `Result` 的な型で返し、呼び出し側に処理を強制する
- COBOL の `ON SIZE ERROR` に相当する形を言語に持ち込むか

任意精度バックエンドを選んだ場合は「あふれない」ことになるが、
その場合でも受け先のスケールへ収めるときに同じ問題が戻ってくる。
