## 問い

10進数の精度とスケールを、型が持つのか、値が実行時に持つのか、その両方か。

- **型が持つ**（COBOL の PIC 流、`Decimal[7,2]`）: スケールの不一致が型エラーになる。
  言語に値パラメータ付きジェネリクスが要る
- **値が持つ**（decimal128 流）: 言語拡張は要らないが、検査はすべて実行時に落ちる
- **両方**: 実行時表現は decimal128、型レベルのスケールは静的検査としてその上に載せる

この決定が、後続の算術規則・リテラル構文・桁あふれの扱いをすべて決める。
