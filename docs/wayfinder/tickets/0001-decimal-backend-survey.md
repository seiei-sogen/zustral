## 問い

Zustral の Decimal が乗れる実行時表現の候補は、実際のところ何がどう違うのか。

最低でも次の3系統について、事実を掘り出す。

- **mpdecimal**（Python の `decimal` が使っている任意精度10進ライブラリ）
- **IEEE 754-2008 decimal128**（GCC の `_Decimal128` / libdfp / Intel DFP ライブラリ）
- **自前の固定小数点**（`__int128` にスケールを添える）

各候補について知りたいこと:

- 確保と解放のモデル。ヒープを使うか、値としてレジスタ／スタックに載るか
  （これが「Decimal は線形リソースか値型か」を直接縛る）
- 精度と桁数の上限、丸めモードの品揃え
- C ABI からの呼び出しやすさ。Zustral は C バックエンド経由でコード生成する
- 依存とライセンス、ビルドの重さ、プラットフォーム移植性
- 演算結果の決定性（プラットフォームをまたいで同じ答えになるか）。金融バッチでは譲れない
